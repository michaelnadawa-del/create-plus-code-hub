Welcome to CREATE+

What is coding?

Coding is the process of writing instructions that tell a computer what to do. People use code to build websites, create apps, solve problems, and make digital tools.

Beginner tip: You do not need to memorise everything. Read each example, copy it, try it in a suitable editor, and change small parts to see what happens.

Try it yourself

Ready-to-copy code examples

Press the Copy Code button, then paste the example into an editor that supports that language.

HTML

1. Make a simple webpage

Creates a page with a title, heading, and short paragraph.

<!DOCTYPE html>
<html>
<head>
  <title>My First Webpage</title>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>I am learning to create websites.</p>
</body>
</html>
CSS

2. Add style to a webpage

Changes the background, text colour, and font.

body {
  background-color: #071a3d;
  color: white;
  font-family: Arial, sans-serif;
  text-align: center;
}
JAVASCRIPT

3. Show a welcome message

Displays a pop-up message when the function is called.

function showMessage() {
  alert("Welcome to CREATE+!");
}

showMessage();
PYTHON

4. Print your first message

Displays two lines of text in the program output.

print("Hello, CREATE+!")
print("I am learning Python.")

How to practise

Follow these simple steps as you explore the examples.

01

Choose

Select a code example and read what it does.

02

Copy

03

Experiment

Remember: HTML, CSS, and JavaScript work together to build websites. Python is a separate language and needs a Python editor or interpreter to run.
